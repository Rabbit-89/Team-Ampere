## Hur registret används

- Varje beslut dokumenteras i en egen Markdown-fil.
- Statusen `gäller` betyder att beslutet fortfarande används.
- Statusen `ersatt` betyder att ett nyare beslut har ersatt det tidigare.
- När ett beslut ändras behåller vi det gamla dokumentet och länkar till det nya beslutet.
- Vi omprövar beslut när de förutsättningar som anges under **Omprövas om** inte längre gäller.
